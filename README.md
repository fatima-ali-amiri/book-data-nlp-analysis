📚 Book Data Collection and NLP Analysis

About the Project

This project focuses on collecting, cleaning, and analyzing book data using Python.

The dataset contains information about 1,000 books.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Kaggle Notebook

📊 Project Features

- Collection of 1,000 books
- Data cleaning and preprocessing
- Missing values and duplicate checking
- Price analysis
- Book rating analysis
- Data visualization using graphs

📈 Project Results

- Total books: 1,000
- Missing values: 0
- Duplicate records: 0
- Average book price: 38.05

🎯 Project Goal

The goal is to understand book data through data analysis and explore how Python can help discover useful information from datasets.
